# Festivite — Formulário de convite

Formulário responsivo e funcional criado com HTML, CSS e JavaScript puro a partir do layout da Rocketseat no Figma.

## Recursos

- Dados do evento e contato.
- Seleção de tipo, cor, tema e estilo.
- Upload de imagem com prévia local.
- Validação de campos obrigatórios, datas, e-mail, telefone, arquivo e termos.
- Confirmação local ao gerar o convite; nenhum dado é enviado a servidores.

## Como visualizar

Abra `index.html` no navegador. Não há dependências ou instalação.
